# Claw 460

A 3D arcade claw machine built in Godot with Claude, as an example for Comp 460, Advanced
Computer Game Creation, at Rice University. It's a work in progress.

**New here? Start with the [setup notes](notes/setup.md).**

## Running it

Open `project.godot` in Godot and press **F5**. Use the arrow keys to orbit the cabinet and
the mouse wheel to zoom. The claw isn't in the cabinet yet, but you can try the grab on its
own: open `grip_test/grip_test.tscn` and press **F6**. Hold Space to lower the claw, release
to close and lift, and press R to restart.
